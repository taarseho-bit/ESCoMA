一、窗口与有效比较位点

窗口长度按人源碱基数计数；人源插入区内的每个非缺口位置对应一个 MSA 列。

全部可能配对位点P = C(n, 2) × w = n(n − 1)w / 2

n 为当前比较类群中通过 QC 的物种数，w 为人源窗口长度。每一对物种在每个窗口列最多贡献一次比较。

若任一序列在该列为缺口“−”或未知碱基“N”，该物种对在此列不计入有效比较。A、C、G、U 为可比较状态；导入数据中的 T 会标准化为 U。

示例 MSA1234
人ACGU
物种 BACGU
物种 CAC−U
物种 DAUGN
n = 4w = 4P = 24

二、保守性：一致性与覆盖度共同约束

高一致性不能抵消大量缺口，因此最终保守性同时惩罚信息缺失。

2.1

平均成对一致性

I = M / V

M：碱基相同的有效物种对位点数；V：排除缺口和 N 后的有效物种对位点总数。

2.2

比对覆盖度

C = V / P

覆盖度衡量全部理论比较中实际具有明确碱基的比例，范围为 0–1。

2.3

窗口保守性得分

Scons = I × C = M / P

范围为 0–1。只有“碱基相同且数据完整”的窗口才能接近 1。

示例结果M = 15V = 18P = 24I = 15/18 = 0.833C = 18/24 = 0.750Scons = 0.625

三、低序列熵：位点碱基分布的一致程度

这里计算的是 MSA 一级序列 Shannon 熵，不是 RNA 构象熵、折叠熵或结构置信度。

位点碱基频率pb,k = count(b at k) / Σx∈{A,C,G,U} count(x at k)计算频率时排除缺口和 N
位点 Shannon 熵Hk = −Σb∈{A,C,G,U} pb,k ln(pb,k)约定 0 × ln(0) = 0；自然对数
归一化低熵LEk = 1 − Hk / ln(4)单一碱基占优时趋近 1；四种碱基均等时为 0
窗口低熵LEW = (1/w) Σk∈W LEk对窗口对应 MSA 列的位点低熵取算术平均
A 100%LE = 1.000
C 75% · U 25%LE = 0.594
A/C/G/U 各 25%LE = 0.000
示例窗口LE₁ = 1.000LE₂ = 0.594LE₃ = 1.000LE₄ = 1.000LEW = 0.899

四、双层筛选、排序与去重

低熵是准入条件，保守性是主排序指标；两者不合并成一个任意加权总分。

全部滑动窗口每种 w 扫描 L − w + 1 个窗口
→
第一层保留 LEW ≥ 阈值当前默认阈值 0.65
→
第二层按 Scons 从高到低同分时依次按低熵、短窗口、靠前坐标
→
独立候选模式同长度窗口重叠比例 < 0.60最多保留 100 个候选
重叠比例R(A,B) = overlap(A,B) / min(|A|, |B|)

仅在相同窗口长度内执行去重。候选按排序依次进入结果集；若与已接收的同长度窗口重叠达到 60%，则跳过该候选。“保留全部窗口”模式不执行此步骤。

窗口 A · 20 nt
窗口 B · 20 nt
重叠 12 nt → R = 12/20 = 0.60 → 独立模式跳过 B

五、坐标、边界与解释限制

人源 ES 坐标
从人源 MSA 序列删除缺口后按 1 开始计数，是滑动窗口和实验靶点设计的主坐标。
人 28S 绝对坐标
人源 ES 坐标加该 ES 在参考 28S 中的起始偏移量，仅用于已经建立可靠坐标映射的 ES。
短 ES
当 ES 长度小于已选窗口长度时，不强行构造 20 nt 窗口，而是将整个 ES 作为一个窗口评分。
比较类群
选择全部真核、后生动物、脊椎动物或哺乳动物会改变 n、P、碱基频率以及最终排行。
定位失败
未通过同源定位 QC 的序列不参与公式计算；这表示当前证据不足，不表示该物种生物学上缺失此 ES。
得分用途
得分用于发现候选保守子区段，不直接证明功能、结构稳定性、可编辑性或实验效应。
保守性 = 平均成对一致性 × 比对覆盖度低熵需在同源定位与MSA后计算人源坐标用于后续编辑靶点设计当前载入人源真实参考；不从单序列推断保守性
